# 问数质量评测规范

## 指标定义

- QuerySpec 有效率：通过结构和语义校验的请求占比。
- 执行成功率：合法请求在目标数据库成功执行的占比。
- 结果正确率：与固定快照上的预期结果按确定性规则一致的占比。
- 端到端成功率：在时限内完成正确回答、必要澄清或正确拒答的占比。
- 权限正确率：不同身份下结果、拒绝和脱敏均符合策略的占比。

执行成功不等于结果正确。超时、异常和错误拒答不得从分母剔除。

## 数据集

每个黄金问题记录工作区/身份、自然语言、预期 QuerySpec 或结果、数值容差、数据快照、语义版本和是否应澄清/拒答。训练、验证、隐藏集分离；模型、提示词或语义变更后重复运行并报告波动。

## badcase 分类

业务词典、指标口径、关系/扇出、权限、数据质量、模型规划、方言编译、数据库执行、结果解释和前端展示。每项包含负责人、复现版本、修复提交和回归状态。

## 当前状态

仅有编译器与安全单元测试，尚未形成企业黄金问题集，也没有真实内网模型准确率结果。任何准确率数字都必须等待真实输入与可重复运行后发布。
